# Запрос на пилот: данные продуктового ритейла для Calmap

Здравствуйте!

Мы разрабатываем мобильное приложение Calmap для планирования здорового рациона
с ограничением по бюджету. Нужен пилотный доступ к данным продуктового ритейла
для показа пользователю актуальной стоимости корзины и наличия ингредиентов в
выбранном магазине.

## Источники и география пилота

- Магнит;
- Пятёрочка;
- Лента;
- Москва и Санкт-Петербург;
- конкретная торговая точка, выбранная пользователем.

## Сценарий

1. Пользователь выбирает магазин.
2. Приложение передаёт список из 10–20 ингредиентов: название, нужное
   количество в граммах и, при наличии, внутренний код продукта.
3. В ответе нужны наиболее релевантные товарные позиции и данные по выбранной
   точке. Мы не создаём корзину и не оформляем заказ у ритейлера.

## Нужные поля ответа

Для каждой найденной позиции:

- сеть и идентификатор/название магазина;
- исходный запрос и нормализованное название товара;
- идентификатор товара у ритейлера;
- `available` — доступен ли товар в выбранной точке;
- цена, валюта и тип цены (обычная/промо);
- вес или объём упаковки;
- ссылка на карточку товара;
- URL изображения, если доступен;
- время наблюдения/обновления;
- признак, что точного совпадения не найдено.

Желаемый JSON-формат одной позиции:

```json
{
  "query": "куриная грудка",
  "retailer": "Магнит",
  "store_id": "780040",
  "store_name": "Магнит у дома, Санкт-Петербургское шоссе, 84",
  "product_id": "1000233462",
  "name": "Филе цыпленка-бройлера",
  "available": true,
  "price": 396.99,
  "currency": "RUB",
  "price_type": "promotion",
  "package_size_g": 1000,
  "product_url": "https://…",
  "image_url": "https://…",
  "observed_at": "2026-08-07T18:13:15Z"
}
```

## Технические требования

- REST API с API key либо webhook с подписью;
- документация и тестовый ключ/песочница;
- лимиты запросов, SLA и частота обновления;
- условия использования и допустимость показа цен/остатков конечным пользователям;
- желательно поиск по свободному тексту, а не только по заранее загруженным SKU;
- для пилота: до 1 000 поисковых запросов в месяц.

## Критерий успешного пилота

По 10 контрольным ингредиентам для выбранных точек в Москве и Санкт-Петербурге
данные должны включать цену и доступность хотя бы по двум сетям, а ответ должен
быть пригоден для автоматического сопоставления с продуктами рациона.

Подскажите, пожалуйста, формат интеграции, стоимость пилота и можно ли получить
пример ответа API до заключения договора.
